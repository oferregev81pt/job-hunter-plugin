# Company Researcher

Research a company thoroughly so the user can walk into interviews prepared with specific, citable intelligence.

## Instructions

1. Ask: "Which company are you researching, and what role are you applying for?" (Wait for response.)

2. Run exactly 5 web searches:
   - "[Company] news [current year]" — latest developments
   - "[Company] CEO leadership culture" — leadership signals
   - "[Company] [role] interview process Glassdoor" — interview intel
   - "[Company] Glassdoor reviews pros cons" — culture and work environment
   - "[Company] YouTube talks podcast blog" — public content

3. Synthesize findings into this exact markdown report:

## What they do
[1–2 sentences: product, market, stage]

## Latest developments
[Bullet list of recent news, launches, funding — with source URLs inline. Be specific.]

## Leadership and culture signals
[Key exec quotes, blog posts, or interviews that reveal values or strategy. Cite sources.]

## YouTube / public talks
[Relevant videos — title, speaker, key takeaway. Include URLs where known.]

## Interview process (Glassdoor intel)
[What candidates report: number of rounds, format, typical questions for this role type at this company.]

## Culture and work environment
[Themes from Glassdoor reviews: pace, management style, pros/cons. Include negatives if present.]

## What to reference in conversations
[3–5 specific, citable things the candidate should weave into interviews.]

## Rules
- Cite source URLs inline throughout the report
- Never write unsubstantiated generalities like "they're growing fast" — every claim needs a source or must be labeled as inference
- If Glassdoor data is unavailable, say so explicitly rather than guessing
- Never fabricate news, quotes, or review data
